# Observed study

`observed-study` is the public label for the recorded three-arm matrix. It is
not a claim that the matrix is complete or publication-ready.

The tracked files are compact derived outputs. They record the frozen settings,
coverage thresholds, paired family-bootstrap contrasts, run accounting, smoke
compatibility check, and complete-pair task data. The raw request, response,
intent, plan, and physical-attempt records are released separately; see
`raw-data.md`.
